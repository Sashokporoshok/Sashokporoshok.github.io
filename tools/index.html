Настройка регистрации на GitHub Pages

  1. Создайте бесплатный проект в Firebase Console и зарегистрируйте в нем веб-приложение (</>), чтобы получить объект firebaseConfig.
  2. В разделе Authentication → Sign-in method включите вход по Email/Password, а во вкладке Settings → Authorized domains добавьте ваш домен ваш-ник.github.io.
  3. В разделе Firestore Database создайте базу данных и вставьте ваш firebaseConfig в переменную CUSTOM_FIREBASE_CONFIG в начале скрипта в файле index.html.
